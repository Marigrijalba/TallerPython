# Taller de Python

**Nombre:** Mariana Grijalba

## 1. Descripción

Este repositorio contiene el desarrollo de ejercicios prácticos orientados al aprendizaje y aplicación de conceptos fundamentales del lenguaje Python.

Cada cuaderno contiene el desarrollo de las actividades propuestas, la documentación correspondiente y la evidencia de ejecución de los ejercicios. Adicionalmente, se incluyen conclusiones sobre los principales conceptos trabajados en cada cuaderno.

## 2. Contenido

| Notebook                       | Tema                                                                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `01-Python-Cadenas.ipynb`      | Operaciones con cadenas de caracteres, incluyendo indexación, slicing, concatenación, secuencias de escape y métodos de manipulación. |
| `02-Python-Tuplas.ipynb`       | Operaciones con tuplas, incluyendo indexación, slicing, búsqueda de índices y ordenamiento.                                           |
| `03-Python-Listas.ipynb`       | Creación y manipulación de listas, indexación, slicing, concatenación, copia y clonación.                                             |
| `04-Python-Conjuntos.ipynb`    | Creación, contenido y operaciones lógicas con conjuntos.                                                                              |
| `05-Python-Diccionarios.ipynb` | Creación y manipulación de diccionarios, uso de llaves y búsqueda de valores.                                                         |
| `06-Python-Condiciones.ipynb`  | Operadores de comparación, sentencias condicionales y operadores lógicos.                                                             |
| `07-Python-Bucles.ipynb`       | Uso de rangos y estructuras de repetición `for` y `while`.                                                                            |
| `08-Python-Funciones.ipynb`    | Creación y uso de funciones, variables y argumentos de diferentes tipos.                                                              |
| `09_Python_Clases.ipynb`       | Creación de clases, atributos, métodos, instancias y objetos en Python.                                                               |
| `Practico_Bono_1.ipynb`        | Ejercicios adicionales para practicar funciones, cadenas, listas, ciclos, condicionales y operadores.                                 |

## 3. Organización del trabajo

Los ejercicios se encuentran organizados en cuadernos independientes según el tema abordado. En cada uno se documenta el desarrollo de las actividades y se presentan los resultados obtenidos mediante la ejecución del código.
